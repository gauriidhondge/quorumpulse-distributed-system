Unit 3 — Synchronization: Election, Mutual Exclusion, Global Snapshot

Coordinator Election (Bully Algorithm)

Shared registry's current coordinator and what each node individually believes — they should converge after an election.

Reservation: Protected vs Unprotected

Same operation, two code paths. "Protected" goes through Ricart-Agrawala mutual exclusion (/mutex/reserve). "Unprotected" goes straight through the Unit 4 object proxy/stub (/objects/reserve), bypassing locking entirely — fire both rapidly against the same donor with 1 unit left to see the race condition the Unit 3 syllabus is about.

Global Snapshot (Chandy-Lamport-inspired)

Takes each node's local process-state snapshot (inventory + logical clocks + mutex state) and totals inventory across the whole network at one instant.

Mini Distributed File System (hand-built)

Blockchain Ledger (Self-Study)

Every successful reservation (protected or unprotected) is appended as a hash-chained block — a tamper-evident audit trail of who reserved what.

Deadlock Detection (Self-Study — Knapp's Classification)

Our live system has only one contested critical section, so it can't actually deadlock. This runs an edge-chasing (Chandy-Misra-Haas style) probe simulation over two synthetic wait-for-graph scenarios instead.
